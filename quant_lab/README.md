# ALFA Quant Lab

Laboratorio offline de descubrimiento y validacion de estrategias por instrumento (forex, metales, indices, cripto) para ALFA CAPITAL.

- Reglas para agentes: `AGENTS.md`
- Mision activa: `MISSION.md`
- Datos: `data/ohlcv_m5/` (M5, ~13 meses, 16 instrumentos, con spread por barra), `data/symbol_specs_bullfy_mt5.json`, `data/forensics/`
- Blueprint NVIDIA Quantitative Signal Discovery (Apache 2.0): `vendor/nvidia_blueprint/`
- Codigo legado de referencia (depende de MT5, no ejecutable aqui): `legacy_strategies/`

Salidas esperadas: `rulebooks/`, `lab/`, `reports/DEEPTEST_REPORT.md`.
